# WaterPath Toolkit Data Sources

All WaterPath Toolkit components, including the [GloWPa model](https://git.wur.nl/glowpa/glowpa-r), are powered by a range of curated data sources, including publicly available datasets, open-access repositories, and relevant databases. By integrating and analyzing these datasets, we have created a list of re-usable data products that are openly available online. 

Please note that the GloWPa model includes a wider range of (mostly static) input datasets that are described in the [model repository](https://git.wur.nl/glowpa/glowpa-r#datasets). 

Each data source is available online, together with a set of scripts that can be used to re-create it (in case of data updates in the future).
